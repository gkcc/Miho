# 终局数据中心：傻瓜版使用说明

## 一分钟上手

1. 关闭已经打开的“终局数据中心”窗口。
2. 双击维护者在**本次最终交付块**中给出的安装包 `.exe`。绝对路径、完整文件名和 SHA-256 必须三项一致；可以直接覆盖安装旧版，不需要先删数据。
3. 安装走到“首次下载并验证 HSR/ZZZ 数据”后耐心等 3–10 分钟。窗口可能像卡住一样暂时不刷新，这是首次数据准备；不要结束安装程序。
4. 安装完成后，按 Windows 键，在开始菜单搜索并打开 **Miho Endgame**。
5. 打开后直接进入当前游戏的 **我的 Box**。点击角色卡即可切换“已拥有 / 未拥有”，程序会自动保存。
6. 需要记录角色练度时，点角色卡上的 **练度**；需要看分析时，点 **终局分析 / 卡池 / 组队推荐**。
7. 日常使用不需要运行任何“任务”。只有想手工刷新公开数据或生成高级报告时，才展开底部的 **更新数据、生成报告与设置**。

如果打开后只有 Microsoft Edge 的“未找到文件 / `ERR_FILE_NOT_FOUND`”，那不是正常界面，也不是你的数据坏了；这是旧错误包。关闭窗口，用本次最终交付块指定的精确安装包原位覆盖安装。

## 安装时应该看到什么

### 安装看起来卡住

首次安装的 `Prepare` 阶段会同时做这些事：

- 下载 HSR 与 ZZZ 数据；
- 生成第一版导出结果；
- 校验结果是否健康；
- 安装每天自动更新的计划任务。

正常耗时通常为 3–10 分钟，网络慢时可能更久。安装日志会先显示“正在首次下载并验证”，完成后再显示“首次数据准备与验证已完成”。只要没有明确弹出失败消息，就先继续等。

### Windows 提示“未知发布者”

当前内部包是 `NotSigned`，Windows SmartScreen 可能拦截。只有在文件来自本项目交付位置、且 SHA-256 与交付信息完全一致时，才选择“更多信息 → 仍要运行”。不要运行来源不明的同名文件。

### 到底该双击哪个安装包

不要在 `target\release\bundle` 里按修改时间猜“最新”，也不要只看 `Miho Endgame` 开头就运行。该目录可能同时保留 active、verification-only 和失败候选。每次可用交付都必须由维护者给出一个最终交付块，至少包含：

```text
绝对路径：D:\...\Miho Endgame_...sha256-<完整摘要>.exe
SHA-256：<64 位十六进制摘要>
签名状态：NotSigned（当前内部版）
```

完整文件名中的摘要、重新计算得到的 SHA-256、交付块三者必须完全一致。没有看到这三项时先不要安装；历史包即使时间更晚，也可能只是未通过门禁的验证候选。

## 第一次打开怎么用

### 1. 维护我的 Box

打开程序后，第一屏就是角色卡片：

- 点击角色卡：切换“已拥有 / 未拥有”；
- 点击卡片上的 **练度**：维护等级、武器/音擎、星魂/影画、专武和培养状态；
- 顶部切换 **崩坏：星穹铁道 / 绝区零**：两款游戏的 Box 分开保存，不会互相覆盖；
- 搜索、属性、命途/特性和拥有状态筛选，只改变当前显示，不会删除数据。

每次修改都会自动保存到本机。看到“本机自动保存”表示当前内容已写入工作区；如果显示“保存失败，请重试”，请先不要继续大量修改，重新点击一次角色卡或重启程序后再确认。

两款游戏的 Box 分别保存在：

```text
<工作区>\.miho\hsr_box_state.json
<工作区>\.miho\zzz_box_state.json
```

Box 页面还提供 **导出 Box / 导入 Box**，可用于手工备份和恢复 JSON。不要手工编辑角色英文 slug。

### 2. 看终局内容

Box 上方的标签直接切换：

- **我的 Box**：维护拥有角色和练度；
- **终局分析**：查看高难模式趋势和角色表现；
- **卡池**：查看当前/后续卡池信息及与已有 Box 的关系；
- **组队推荐**：按当前 Box 查看已有数据支持的组队建议。

这些页面使用同一个 Box，不需要在 Visualizer 和桌面 APP 之间重复录入。

### 3. 更新数据（平时不用操作）

安装器和每日计划任务会维护公开数据。想立即手工刷新时：

1. 展开页面底部的 **更新数据、生成报告与设置**；
2. 在“更新公开数据”里点对应游戏的 **立即更新**；
3. 到“本次运行进度”看结果；显示“完成”后重新载入 Box/分析页面即可。

“本次运行进度”只是更新和报告的运行记录，不是需要你完成的待办。运行编号、状态流水和结果类型都收在 **技术详情** 里；失败原因仍会直接显示。

### 4. 工作区（高级）

工作区就是配置、导出结果、Box 和报告放置的位置。普通用户保持默认即可：

```text
%APPDATA%\com.miho.endgame
```

快速打开：按 `Win + R`，粘贴上面这一行，按回车。

“切换工作区”适合想把结果放到其他磁盘的人。请选择一个已经存在的普通本地文件夹；程序会补齐缺失的默认配置，并让每日任务跟随新工作区。任务正在运行时不能切换。不要选择快捷方式、符号链接、网盘占位目录或系统目录。

### 5. 生成报告（可选）

展开工具区后使用“生成分析报告（高级）”。如果按钮不可点，页面会直接列出“缺少输入”。

- **整理可用证据**：汇总公开数据并标注可靠性；
- **检查队伍覆盖**：比较当前 Box 与规划角色；
- **分析抽卡价值**：生成 `current / next` 抽取价值报告；
- **生成复核材料**：导出供外部模型或人工复核的证据载荷。

“规划角色 slugs”是可选的英文稳定标识；“规划状态”通常用 `next`，抽取价值与复核包通常用 `current, next`。不知道高级参数含义时，保留界面默认值即可。

## 结果放在哪里

默认工作区为 `%APPDATA%\com.miho.endgame`：

```text
%APPDATA%\com.miho.endgame\out       HSR 导出、Workbook、Visualizer
%APPDATA%\com.miho.endgame\out_zzz   ZZZ 导出、Workbook、Visualizer、报告
%APPDATA%\com.miho.endgame\configs   两款游戏的更新与报告配置
%APPDATA%\com.miho.endgame\.miho     Box 与桌面工作区状态
```

切换工作区后，把上面的 `%APPDATA%\com.miho.endgame` 换成所选目录即可。任务卡片只显示安全的逻辑名称，不直接暴露完整本机路径。

常见报告文件包括：

- `evidence_pool_summary.md`
- `current_box_team_coverage.md`
- `target_box_team_coverage.md`
- `current_pull_value_report.md` / `next_pull_value_report.md`
- `current_gpt_pull_reviewer_packet.md` / `next_gpt_pull_reviewer_packet.md`

## 每日自动更新

安装器会创建当前 Windows 用户专属的任务：

```text
MihoEndgameDailyUpdate-<当前用户 SID 的哈希>
```

默认每天 09:30 运行；要求当前用户处于登录状态。错过时间后，Windows 会在可用时补跑。桌面程序不用一直开着。任务不会并行启动第二份，最长运行 2 小时。

想确认任务是否存在，可以打开 PowerShell 执行：

```powershell
Get-ScheduledTask -TaskName 'MihoEndgameDailyUpdate-*' |
  Select-Object TaskName, State
```

正常空闲状态是 `Ready`。卸载程序会删除这项每日任务。

## 常见问题

### 打开后是 Edge“未找到文件”

这是旧 EXE 的前端资源打包错误。关闭它，重新运行本次最终交付块中路径和 SHA-256 完全匹配的安装包做原位升级。不要为了这个错误删除 `%APPDATA%\com.miho.endgame`。

### 双击后立刻没了

1. 确认启动的是开始菜单里的 **Miho Endgame**，不是下载目录或旧安装目录残留的 `miho-desktop.exe`。
2. 再运行一次本次最终交付块指定的同一个安装包；安装会先恢复未完成事务，再原位升级。
3. 若安装器明确失败，把这个文件连同截图交给维护者：

   ```text
   %LOCALAPPDATA%\com.miho.endgame.installer-last-failure-v1.json
   ```

4. 若安装成功但仍闪退，可在 PowerShell 中从实际安装目录启动并保留报错：

   ```powershell
   & 'D:\Miho Endgame\miho-desktop.exe' 2> "$env:TEMP\miho-desktop-stderr.txt"
   ```

   如果安装在别处，请替换路径；然后把 `%TEMP%\miho-desktop-stderr.txt` 和截图交给维护者。

### “立即更新”按钮是灰色

先看按钮下方提示：通常是能力仍在刷新、配置缺失，或已有另一个操作正在运行。等当前操作结束；仍提示缺输入时，在折叠工具区刷新能力并检查工作区 `configs`。

### 导出或报告失败

不要反复连点。展开卡片的“技术详情”，记录运行编号和错误代码；确认网络正常后再重试一次。写入阶段失败不会把半成品当作正式结果。

### 可以删除哪些东西

- 不要手动删 `%APPDATA%\com.miho.endgame`，这里是默认工作区和用户数据。
- 不要手动删安装目录里的单个脚本或 EXE；需要清理时用 Windows“已安装的应用”卸载。
- 开发仓库里的 `target/debug`、release scratch 和临时构建目录是可再生缓存，可以由维护者清理；普通用户无需接触。

## 卸载与数据保留

从 Windows“设置 → 应用 → 已安装的应用”卸载 **Miho Endgame**。卸载会移除程序、快捷方式、注册信息和每日任务，但始终保留以下用户工作区：

```text
%APPDATA%\com.miho.endgame
```

确认以后不再需要导出、Box、报告和配置时，再由你手工备份并删除该目录。安装器不会替你递归删除这些数据。
